# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-09-10

### Added
- **Active Days Configuration**: Users can now select specific days of the week on which the timer/alarms should be active. On unselected days, the timer continues to run silently in the background without triggering loud alarms or recording missed events. Implemented on both Android and Webapp platforms.
